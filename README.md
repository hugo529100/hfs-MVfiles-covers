This plugin needs to be used together with the ffmpeg, because ffmpeg will extract cover images when you open music or video files and store them in the `\cache\videothumbnail` folder inside the corresponding directory.

When browsing the frontend, if you're navigating through a large folder and feel that it's consuming too much memory, you can temporarily disable it in the options panel.

If the thumbnails are stored on a mechanical hard drive, it may cause excessive read operations. In that case, I recommend configuring the settings in the backend control panel to store all thumbnails on an SSD instead. This will greatly improve performance and prevent the mechanical drive from slowing down.

Of course, these features require a bit of trial and error to get used to, but at least for now, it's stable and quite satisfying.

Recommended companion plugins:

- hfs-click-icon-to-show-main
- Orange-theme-main
- Hide-file
- Frontend-performance-optimizer
- File-icon-fix
- thumbnails-main
- sharp-main
